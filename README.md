# homebrew-tfgql

Homebrew tap for [tfgql](https://github.com/jeremymefford/tfgql) - TFC/E GraphQL Facade

## Installation

```bash
brew tap jeremymefford/tfgql
brew install tfgql
```

## Usage

After installation, you can run tfgql:

```bash
tfgql
```

For more information about tfgql, visit the [official documentation](https://jeremymefford.github.io/tfgql/).
